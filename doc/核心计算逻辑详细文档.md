## 1. 月度报表 PT3/PT4 核心逻辑

### 1.1 整体处理流程

```
上传 payment_transaction_file.csv (必需)
         │
         ▼
┌─────────────────────────────────────┐
│     monthly_report_script.run()     │
│                                     │
│  1. _read_transactions()            │
│     → 读取 CSV，按站点解析数字格式   │
│                                     │
│  2. _classify_rows()                │
│     → 将行数据分类到 25+ 类别        │
│                                     │
│  3. 计算 PT3 详细收支 (40+ 字段)    │
│     → 按SKU/类型聚合                │
│                                     │
│  4. 计算 PT4 简化汇总               │
│     → 收入4类 + 支出6类 + amazon_pay_back │
│                                     │
│  5. 生成 Excel 工作簿               │
│     → 总览草稿 / 报表核算 / 交易一览  │
│     → 销售SKU明细 / 退款SKU明细      │
└─────────────────────────────────────┘
```

### 1.2 交易分类（25+ 类别）

`_classify_rows()` 函数将所有 payment 行分类到以下类别：

#### 第一层分类（按 type 字段）
| 类别 key | 说明 | 判断条件 |
|----------|------|----------|
| `order` | 所有订单 | `type == "Order"` |
| `refund` | 所有退款 | `type == "Refund"` |
| `fba_customer_return_fee` | FBA 客户退货费 | `type == "FBA Customer Return Fee"` |
| `amazon_fees_reversal` | 亚马逊费用撤销 | `type == "Amazon Fees - Reversal"` |
| `chargeback_refund` | 拒付退款 | `type == "Chargeback Refund"` |
| `liquidation` | 清算 | `type == "Liquidations"` |
| `adjustment` | 调整 | `type == "Adjustment"` |
| `service_fee` | 服务费 | `type == "Service Fee"` |
| `fba_inventory_fee` | FBA 库存费 | `type == "FBA Inventory Fee"` |
| `amazon_fees` | 亚马逊费用 | `type == "Amazon Fees"` |
| `fee_adjustment` | 费用调整 | `type == "Fee Adjustment"` |
| `deal_fee` | 促销活动费 | `type == "Deal Fee"` |
| `debt` | 债务/信用卡扣款 | `type == "Debt"` |
| `fba_transaction_fees` | FBA 交易费 | `type == "FBA Transaction fees"` |

#### 第二层分类（按 fulfillment 字段细分）
| 类别 key | 说明 | 判断条件 |
|----------|------|----------|
| `fba_order` | FBA 订单 | `type == "Order" AND fulfillment == "Amazon"` |
| `fbm_order` | FBM 订单 | `type == "Order" AND fulfillment == "Seller"` |
| `fba_refund` | FBA 退款 | `type == "Refund" AND fulfillment == "Amazon"` |
| `fbm_refund` | FBM 退款 | `type == "Refund" AND fulfillment == "Seller"` |

#### 特殊分类（按 description 字段细分）
| 类别 key | 说明 | 判断条件 |
|----------|------|----------|
| `adjustment_income` | 调整收入 | `type == "Adjustment"` 且 description 不含 "FBA Inventory Reimbursement - General Adjustment" 和 "Non-subscription Fee Adjustment" |
| `adjustment_expense` | 调整支出 | `type == "Adjustment"` 且 description 含 "FBA Inventory Reimbursement - General Adjustment" 或 "Non-subscription Fee Adjustment" |
| `advertising` | 广告费 | `type == "Service Fee"` 且 description == "Cost of Advertising" |
| `service_refund_for_advertiser` | 广告退款 | `type == "Service Fee"` 且 description == "Refund for Advertiser" |
| `agl_selection` | AGL 国际运费 | `type == "Service Fee"` 且 description 含 "FBA International Freight" |
| `amazon_fees_and_service_fee_without_ad` | 不含广告的服务费 | `amazon_fees` 或 `service_fee` 中排除广告相关 |
| `price_discount` | 价格折扣 | `type` 为空且 description 以 "Price Discount" 开头 |
| `fee_adjustment_weight_dim` | 重量尺寸费用调整 | `type == "Fee Adjustment"` 且 description == "Fee Adjustment - Weight and Dimension Change" |

### 1.3 收入分类计算

```python
# === 收入项计算 ===

# FBM 销售额
product_sales_non_fba = sum(FBM订单.product_sales)

# FBM 退款
product_sale_refunds_non_fba = sum(FBM退款.product_sales)

# FBA 销售额
fba_product_sales = sum(FBA订单.product_sales)

# FBA 退款（含 product sales + other 列）
fba_product_sale_refunds = abs(sum(FBA退款.product_sales) + sum(FBA退款.other))

# FBA 库存赔偿收入
fba_inventory_credit = sum(调整收入.total)

# FBA 清算收入
fba_liquidation_proceeds = sum(清算.product_sales)

# 运费收入
shipping_credits = sum(所有订单.shipping_credits)

# 运费退款
shipping_credit_refunds = sum(所有退款.shipping_credits)

# 礼品包装收入
gift_wrap_credits = sum(所有订单.gift_wrap_credits)

# 礼品包装退款
gift_wrap_credits_refunds = sum(所有退款.gift_wrap_credits)

# 促销折扣
promotional_rebates = sum(所有订单.promotional_rebates)

# 促销折扣退款
promotional_rebate_refunds = sum(所有退款.promotional_rebates)

# 拒付
chargebacks = sum(拒付退款.total)

# A-to-z 保障索赔（目前为 0）
a_to_z_guarantee_claims = Decimal("0")

# SAFE-T 赔偿（目前为 0）
safe_t_reimbursement = Decimal("0")

# === 收入合计 ===
income_total = (
    product_sales_non_fba
    + product_sale_refunds_non_fba
    + fba_product_sales
    + fba_product_sale_refunds
    + fba_inventory_credit
    + fba_liquidation_proceeds
    + shipping_credits
    + shipping_credit_refunds
    + gift_wrap_credits
    + gift_wrap_credits_refunds
    + promotional_rebates
    + promotional_rebate_refunds
    + chargebacks  # 不含 a_to_z 和 safe_t（均为0）
)
```

### 1.4 支出分类计算

```python
# === 支出项计算 ===

# FBM 销售佣金
seller_fulfilled_selling_fees = sum(FBM订单.selling_fees)

# FBA 销售佣金
fba_selling_fees = sum(FBA订单.selling_fees)

# 销售佣金退款
selling_fee_refunds = sum(所有退款.selling_fees)

# FBA 派送费（含交易费和调整）
fba_transaction_fees_total = (
    sum(FBA订单.fba_fees) + sum(FBA交易费.fba_fees)
)

# FBA 派送费退款（含重量尺寸调整费）
fba_transaction_fee_refunds = (
    sum(FBA退款.fba_fees) + sum(重量尺寸费用调整.total)
)

# FBA 库存和入库服务费
fba_inventory_and_inbound_services_fees = (
    sum(FBA库存费.total)
    + sum(FBA客户退货费.total)
    + sum(AGL国际运费.total)
)

# 服务费（不含广告）
service_fees_without_ads = sum(
    service_fee.description 不在 [
        "Cost of Advertising",
        "Refund for Advertiser",
        "FBA International Freight Shipping Charge",
        "FBA International Freight Duties and Taxes Charge"
    ].total
)
service_fees = (
    sum(amazon_fees.total)  # 优惠券费用等
    + service_fees_without_ads
    + sum(deal_fee.total)  # LD费用
    + sum(price_discount.total)  # 价格折扣
    + sum(amazon_fees_reversal.total)  # 优惠券基础费撤销
)

# 调整项（库存赔偿等支出）
adjustments = sum(调整支出.total)

# 广告成本
cost_of_advertising = sum(广告费.total)

# 广告退款
refund_for_advertiser = sum(广告退款.total)

# 清算手续费
liquidations_fees = sum(清算.other_transaction_fees)

# === 支出合计 ===
expense_total = (
    seller_fulfilled_selling_fees
    + fba_selling_fees
    + selling_fee_refunds
    + fba_transaction_fees_total
    + fba_transaction_fee_refunds
    + other_transaction_fees
    + other_transaction_fee_refunds
    + fba_inventory_and_inbound_services_fees
    + shipping_label_purchases
    + shipping_label_refunds
    + carrier_shipping_label_adjustments
    + service_fees
    + refund_administration_fees
    + adjustments
    + cost_of_advertising
    + refund_for_advertiser
    + liquidations_fees
    + receivables
    + deductions
    + amazon_shipping_charge_adjustments
)
```

### 1.5 PT4 简化汇总公式

PT4 是对 PT3 的简化汇总，用于快速查看月度财务状况：

```python
# === PT4 收入汇总 ===
pt4_income_sales = (
    product_sales_non_fba
    + fba_product_sales
    + shipping_credits
    + gift_wrap_credits
    + promotional_rebates
)

pt4_income_refund = (
    product_sale_refunds_non_fba
    + fba_product_sale_refunds
    + shipping_credit_refunds
    + gift_wrap_credits_refunds
    + promotional_rebate_refunds
)

pt4_income_adjustment = (
    fba_inventory_credit
    + fba_liquidation_proceeds
)

pt4_income_chargeback = (
    chargebacks
    + a_to_z_guarantee_claims
    + safe_t_reimbursement
)

pt4_income_total = (
    pt4_income_sales
    + pt4_income_refund
    + pt4_income_adjustment
    + pt4_income_chargeback
)

# === PT4 支出汇总 ===
pt4_expense_selling_fee = (
    seller_fulfilled_selling_fees
    + fba_selling_fees
    + selling_fee_refunds
)

pt4_expense_fba_fee = (
    fba_transaction_fees_total
    + fba_transaction_fee_refunds
)

pt4_expense_inventory_fee = fba_inventory_and_inbound_services_fees

pt4_service_fee = service_fees

pt4_expense_advertising = (
    cost_of_advertising
    + refund_for_advertiser
)

pt4_expense_other_fees = (
    adjustments
    + liquidations_fees
    + other_transaction_fees
    + other_transaction_fee_refunds
    + receivables
    + deductions
    + amazon_shipping_charge_adjustments
    + shipping_label_purchases
    + shipping_label_refunds
    + carrier_shipping_label_adjustments
)

pt4_expense_total = (
    pt4_expense_selling_fee
    + pt4_expense_fba_fee
    + pt4_expense_inventory_fee
    + pt4_service_fee
    + pt4_expense_advertising
    + pt4_expense_other_fees
)

# === PT4 核心公式 ===
amazon_pay_back = pt4_income_total + pt4_expense_total
# ⚠️ 注意：expense_total 本身为负数（各项费用以负值存储）
# 因此 amazon_pay_back = 收入合计 + 支出合计
```

### 2.4 40+ 指标计算公式

```python
# === 流量与转化 ===
总转化         = 总销量 / 页面浏览量
广告点击率     = 广告点击量 / 广告展示量
广告单占比     = 广告订单量 / 总销量
广告转化率     = 广告订单量 / 广告点击量
CPC            = 广告花费 / 广告点击量
ACOS           = 广告花费 / 广告销售额
SP占比         = 广告花费 / 总销售额

# === 自然流量（核心公式）===
自然流量       = 页面浏览量 - 广告点击量
自然流量占比   = 自然流量 / 页面浏览量
自然单         = 总销量 - 广告订单量
自然单转化     = 自然单 / 自然流量

# === 成本计算（FOB + 头程）===
产品FOB        = 实际销售量 × FOB单价       # 从 ProductCost 获取，按年月汇率转换
销售头程       = 实际销售量 × 头程单价       # 从 ProductCost 获取

# === 成本占比 ===
成本占比       = 产品FOB / 实际销售额
头程占比       = 销售头程 / 实际销售额
配送费占比     = FBA配送费 / 实际销售额
佣金占比       = 平台佣金 / 实际销售额
总成本占比     = 总成本 / 实际销售额

# === 总成本与利润（核心公式）===
总成本         = 产品FOB + 销售头程 + FBA配送费 + 平台佣金
利润           = 实际销售额 - 总成本 - 广告花费 - 实际退款额
利润率         = 利润 / 实际销售额

# === 其他指标 ===
平均售价       = 实际销售额 / 实际销售量
退款率         = 实际退款额 / 实际销售额
```

### 2.5 汇总行计算

汇总行（SKU = "汇总"）在明细行之后追加，所有数值指标使用 `sum()` 聚合，自然流量/自然单使用差值公式：

```python
汇总.自然流量 = 汇总.页面浏览量 - 汇总.广告点击量
汇总.自然单   = 汇总.总销量 - 汇总.广告订单量
# 其他指标同明细行计算方式
```

## 3. 日分析聚合逻辑

### 3.1 整体流程

```
输入：project_id, country, start_date, end_date, (可选) sku
         │
         ▼
┌─────────────────────────────────────────────────────────────┐
│  build_daily_analysis()                                    │
│                                                             │
│  1. Redis 缓存查询（sku=None 时）                           │
│                                                             │
│  2. _load_sales_metrics()     → order_qty, sales_amount    │
│     AnalysisSalesOrderRow + AnalysisSourceFile              │
│     条件: report_type='sales_report', is_current=True      │
│           is_counted_sales=True                             │
│                                                             │
│  3. _load_ad_metrics()         → impressions, clicks,       │
│                                 spend, orders_7d            │
│     AnalysisAdProductRow + AnalysisSourceFile              │
│     条件: report_type='ad_product_report', is_current=True │
│           scope_status='included_product'                  │
│                                                             │
│  4. _load_inventory_metrics() → available_qty               │
│     InventorySnapshotRow + AnalysisSourceFile              │
│     条件: report_type='inventory_report'                    │
│                                                             │
│  5. 按 (date, sku) 聚合到 _MetricBucket                     │
│                                                             │
│  6. 生成 summary_rows (按日期) + detail_rows (按日期+SKU)  │
│                                                             │
│  7. Redis 缓存（sku=None 时）                               │
└─────────────────────────────────────────────────────────────┘
```

### 3.2 按 (date, sku) 聚合

```python
@dataclass
class _MetricBucket:
    asin: str | None = None
    order_qty: int = 0                 # 累加
    sales_amount: Decimal = Decimal("0")  # 累加
    impressions: int = 0               # 累加
    clicks: int = 0                     # 累加
    ad_spend: Decimal = Decimal("0")    # 累加
    ad_orders: int = 0                  # 累加
    available_qty: int = 0              # 累加

# detail_row 输出格式
detail_row = {
    "date": day_text,
    "sku": bucket_sku,
    "asin": bucket.asin,
    "order_qty": int(bucket.order_qty),
    "sales_amount": _round_money(bucket.sales_amount),
    "impressions": int(bucket.impressions),
    "clicks": int(bucket.clicks),
    "cpc": _safe_ratio(bucket.ad_spend, bucket.clicks),    # ad_spend / clicks
    "ad_spend": _round_money(bucket.ad_spend),
    "ad_orders": int(bucket.ad_orders),
    "available_qty": int(bucket.available_qty),
}

# summary_row 输出格式（按日期聚合 sku）
summary_row = {
    "date": day_text,
    "order_qty": sum(all_skus.order_qty),
    "sales_amount": _round_money(sum(all_skus.sales_amount)),
    "impressions": sum(all_skus.impressions),
    "clicks": sum(all_skus.clicks),
    "cpc": _safe_ratio(sum(ad_spend), sum(clicks)),
    "ad_spend": _round_money(sum(ad_spend)),
    "ad_orders": sum(all_skus.ad_orders),
    "available_qty": sum(all_skus.available_qty),
}
```

### 3.3 指标计算

```python
# CPC（每次点击成本）
cpc = ad_spend / clicks  (clicks 为 0 时返回 0)

# 金额保留两位小数
_round_money(value) = float(Decimal(value).quantize(Decimal("0.01"), rounding=ROUND_HALF_UP))
```

### 4.3 德语数字格式（逗号作小数点）

`parse_localized_number()` 处理 DE 站点数字格式：

```python
def parse_localized_number(value: Any, locale: str) -> float:
    text = str(value).strip()

    # 检测负数格式：(123.45) → -123.45
    negative = text.startswith('(') and text.endswith(')')

    # 移除非数字字符（保留逗号、点、负号）
    cleaned = ''.join(ch for ch in text if ch.isdigit() or ch in {',', '.', '-', '(', ')'})

    if locale == 'de':
        # DE 格式：1.234,56 → 1234.56
        #   先去掉千位分隔符（点），再将逗号替换为小数点
        cleaned = cleaned.replace('.', '').replace(',', '.')
    else:
        # EN 格式：1,234.56 → 1234.56
        #   如果同时有逗号和点，去掉逗号；否则也去掉逗号
        if ',' in cleaned and '.' in cleaned:
            cleaned = cleaned.replace(',', '')
        elif ',' in cleaned:
            cleaned = cleaned.replace(',', '')

    number = float(cleaned)
    return -number if negative and number > 0 else number
```

### 4.4 交易类型本地化

`normalize_payment_type()` 将本地化类型名映射到标准英文：

```python
PAYMENT_TYPE_ALIASES = {
    'Order':  ['order', 'bestellung'],
    'Refund': ['refund', 'erstattung'],
}

def normalize_payment_type(value: Any) -> str:
    normalized = _normalize_payment_token(str(value))
    # _normalize_payment_token: 转小写 + 去除 \ufeff + 替换德语特殊字符(ä→ae等)
    for canonical, aliases in PAYMENT_TYPE_ALIASES.items():
        if normalized in {_normalize_payment_token(a) for a in aliases}:
            return canonical
    return str(value).strip()
```
