# 公共模块与关联

## 一、模块间关联图

```
Project (项目)
    ↓ 归属
AnalysisSourceFile (源文件)
    ↓ 包含
AnalysisBusinessRow / AnalysisPaymentRow / AnalysisAdProductRow / InventorySnapshotRow / AnalysisSalesOrderRow
    ↓ 聚合
AnalysisPT1Calculation (周度 PT1)
    ↓ 计算
AnalysisPTSKUDetail (SKU 明细)

MonthlyReport (月度报表)
    ↓ 包含
MonthlyReportTransaction (交易明细)
    ↓ 汇总
MonthlyReportPT3Calculation (详细收支)
MonthlyReportPT4Calculation (简化 P&L)

共享依赖：
ProductCost ← PT1 计算需要 FOB/头程成本
ExchangeRate ← 币种转换 (RMB → USD/EUR/GBP)
```

## 二、ProductCost 模块

- **用途**：存储每 SKU 的 FOB 单位成本和头程单位成本（RMB）
- **使用场景**：PT1 利润计算
- **依赖**：ExchangeRate 进行币种转换

## 三、ExchangeRate 模块

- **用途**：存储年月份对应的汇率
- **使用场景**：RMB → USD/EUR/GBP 转换
- **查找键**：year_month (yyyy-mm)

## 五、可优化机会

### 1. 可公共化的逻辑

#### Country Normalization 统一

- **当前状态**：在 6 处文件中重复实现，国家别名映射分散
- **优化目标**：提取为 `shared_utils.normalize_country()`，统一管理国家别名映射表
- **实现复杂度**：低（仅涉及代码迁移和映射表整理）

#### _safe_div 统一

- **当前状态**：多处实现返回类型不一致（0 / 0.0 / "0.00%"）
- **优化目标**：统一工具函数，规定返回值类型和格式
- **实现复杂度**：低（仅涉及工具函数统一）

#### 内存任务存储持久化

- **当前状态**：MonthlyReportTask、AnalysisReportTask 存于模块级 dict，服务器重启丢失
- **优化目标**：迁移至 Celery + Redis 或数据库持久化任务状态
- **实现复杂度**：高（需重构任务队列架构）

#### 缓存管理统一

- **当前状态**：各 service 独立管理缓存，失效逻辑不一致
- **优化目标**：统一 cache service，集中管理缓存键和失效策略
- **实现复杂度**：中（需抽象缓存接口）

### 2. 数据模型层面

#### ProductCost 表扩展

- **当前状态**：存储 FOB/头程成本，用于 PT1 计算
- **优化目标**：支持更多成本维度（仓储费、平台费等的单位成本）
- **实现复杂度**：中（需扩展表结构和计算逻辑）

#### ExchangeRate 表扩展

- **当前状态**：支持 RMB → USD/EUR/GBP 转换
- **优化目标**：支持更多币种和实时汇率
- **实现复杂度**：中（需扩展表结构和数据源）

#### AnalysisSourceFile 统一管理

- **当前状态**：源文件解析逻辑分散在各 service
- **优化目标**：统一源文件解析层，统一元数据管理
- **实现复杂度**：中（需抽象文件解析接口）

### 3. API 层面

#### 源文件上传逻辑合并

- **当前状态**：source 文件上传逻辑在各 endpoint 重复
- **优化目标**：合并为统一的上传 service，统一文件校验
- **实现复杂度**：中（需重构上传接口）

#### 周报/月报 recompute 逻辑抽象

- **当前状态**：周报和月报的重新计算逻辑分散
- **优化目标**：抽象统一的 recompute 框架，支持增量/全量计算
- **实现复杂度**：高（涉及计算流程重构）

### 4. 性能优化机会

| 优化项 | 当前状态 | 优化目标 | 实现复杂度 |
|--------|---------|---------|-----------|
| 索引优化 | AnalysisSourceFile.report_date 已有 idx 但字段 nullable | 确保 nullable 字段索引有效，或改用 composite index | 低 |
| Redis 缓存策略 | 日分析结果缓存时间可能过短 | 延长缓存时间，减少重复计算 | 低 |
| N+1 查询优化 | daily_analysis_service 存在循环内查询 | 批量加载优化，预加载关联数据 | 中 |
| 数据库连接池 | 可能使用默认配置 | 调整连接池大小，优化查询性能 | 低 |

### 5. 可扩展方向

| 方向 | 当前状态 | 扩展目标 | 实现复杂度 |
|------|---------|---------|-----------|
| 更多国家支持 | payment_report_locale 仅支持部分国家 | 扩展国家别名映射表和支持的报表格式 | 低 |
| 更多报表类型 | 目前支持财务、广告、库存等报表 | 支持税务报告、采购报表等 | 高 |
| 自动化调度 | 目前为手动触发 | Celery beat periodic tasks 自动化执行 | 中 |
