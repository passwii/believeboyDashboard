# Data-Reporting 模块业务逻辑

## 模块概述

Data-Reporting 模块负责生成各类运营报表，包括月度报表、日报表和产品分析报表。

---

## 月度报表生成流程

### 上传阶段
```
用户上传:
  - payment_report.csv (必需)
  - monthly_summary_pdf (可选)
```

### API 调用
```
POST /api/v1/monthly-reports
```

### 后台处理流程
```
┌─────────────────────────────────────────────────────────────┐
│                  monthly_report.py 后台任务                  │
│                                                             │
│  1. 读取 transaction CSV 文件                               │
│  2. 分类 25 种交易类型                                      │
│  3. 计算 PT3 (详细) 和 PT4 (简化)                           │
│  4. 生成 Excel 工作簿                                       │
└─────────────────────┬───────────────────────────────────────┘
                      ▼
┌─────────────────────────────────────────────────────────────┐
│                   Excel 工作簿内容                          │
│                                                             │
│  → 总览草稿                                                  │
│  → 报表核算                                                  │
│  → 交易一览                                                  │
│  → 销售 SKU 明细                                            │
│  → 退款 SKU 明细                                            │
└─────────────────────────────────────────────────────────────┘
```

### 交易分类（25 种类别）

#### 订单类
| 类型 | 说明 |
|------|------|
| FBA Order | FBA 订单收入 |
| FBM Order | FBM 订单收入 |

#### 退款类
| 类型 | 说明 |
|------|------|
| FBA Refund | FBA 退款 |
| FBM Refund | FBM 退款 |

#### 调整类
| 类型 | 说明 |
|------|------|
| 库存信贷 | 库存调整产生的收入 |
| 费用调整 | 费用多收/少收调整 |

#### 费用类
| 类型 | 说明 |
|------|------|
| Amazon Fees | 平台佣金 |
| Service Fee | 服务费 |
| FBA Inventory Fee | FBA 仓储费 |
| Deal Fee | 促销活动费 |

#### 广告类
| 类型 | 说明 |
|------|------|
| Cost of Advertising | 广告费用 |
| Refund for Advertiser | 广告退款 |

#### 特殊类
| 类型 | 说明 |
|------|------|
| Liquidation | 库存清算 |
| Chargeback | 拒付 |
| A-to-z | A-to-z 保障索赔 |
| SAFE-T | SAFE-T 赔偿 |
| AGL | AGL 费用 |

## 日报表生成流程

### 上传阶段
```
用户上传 3 个文件:
  - sales_report.tsv (销售报告)
  - ad_report.xlsx (广告报告)
  - inventory_report.tsv (库存报告)
```

### API 调用
```
POST /api/v1/daily-reports
```

### 处理流程
```
┌─────────────────────────────────────────────────────────────┐
│                   日报表聚合脚本                             │
│                                                             │
│  聚合 SKU 级别指标:                                         │
│  → order_qty (订单数量)                                    │
│  → sales_amount (销售额)                                   │
│  → impressions (展示次数)                                   │
│  → clicks (点击次数)                                        │
│  → CPC (点击成本)                                           │
│  → ad_spend (广告花费)                                      │
│  → ad_orders (广告订单)                                     │
│  → available_stock (可用库存)                               │
└─────────────────────┬───────────────────────────────────────┘
                      ▼
┌─────────────────────────────────────────────────────────────┐
│                   生成 Excel 报表                           │
└─────────────────────────────────────────────────────────────┘
```

## 产品分析流程（周度）

### 上传阶段
```
用户上传文件:
  - business_report.csv (业务报告)
  - payment_report.csv (支付报告)
  - ad_report.xlsx (广告报告)
  - inventory_report.txt (可选，库存报告)
```

### API 调用
```
POST /api/v1/product-analysis
```

### 处理流程
```
┌─────────────────────────────────────────────────────────────┐
│                   产品分析脚本                               │
│                                                             │
│  1. 读取各报告文件                                          │
│  2. 按 SKU 合并数据                                         │
│  3. 计算 45+ 指标/每 SKU                                   │
│  4. 存储 PT1 计算结果                                       │
└─────────────────────────────────────────────────────────────┘
```

## 定价计算（Pricing Calculation）

### FBA 报价计算
- 计算 FBA 头程成本
- 计算 FBA 配送费
- 计算平台佣金
- 计算最终报价

### FBM 报价计算
- 计算产品成本
- 计算 FBM 物流成本
- 计算平台佣金
- 计算最终报价

### 反向报价（Reverse Quote）
```
基于目标售价，反向推算各项成本占比
```

### 成本反向（Reverse Cost）
```
基于目标利润，反向推算可接受的成本区间
```

## 报表文件格式

### TSV 文件
- 分隔符：制表符 `\t`
- 编码：UTF-8

### XLSX 文件
- Excel 2007 及以上格式
- 支持多工作表

### CSV 文件
- 分隔符：逗号 `,`
- 编码：UTF-8
- 支持德语站点特殊格式（逗号作小数点）
