# 数据分析-产品分析 前端需求

## 1. 页面目标

支持多文件预上传并生成产品分析表（SKU级），可选附带库存详情。

## 2. 路由与导航

- 建议路由：`/dashboard/data-analysis/product-analysis`
- 菜单建议：`数据分析 > 产品分析`

## 3. 页面结构

1. 参数区：
- 项目名称（下拉，来源 projects.csv）
- 开始日期 `report_start_date`
- 结束日期 `report_end_date`
- 快捷按钮：`上周`（一键填充上周一到上周日）

2. 上传区（4卡片）：
- 商业报告（必需）
- 付款报告（必需）
- 广告报告（必需）
- 库存报告（可选）

3. 操作区：
- 生成分析表
- loading 与禁用态

4. 结果区：
- 下载成功提示
- 文件名展示
- 错误提示

## 4. 字段与接口参数

提交接口（脚本 `/submit`）：

- `project_name`
- `report_start_date`
- `report_end_date`
- `business_report_path`
- `payment_report_path`
- `ad_report_path`
- `inventory_report_path`（可选；当前脚本变量名仍有 `fba_report_path`）

上传接口公共字段：

- `file`
- `project_name`
- `file_type`

建议 file_type（文档统一值）：

- `business_report`
- `payment_report`
- `ad_report`
- `inventory_report`

已确认：产品分析上传 `file_type` 统一按上述 4 个值，不使用 `ad_product_report`、`fba_report`。

## 5. 交互规则

1. 必填参数和3个必需文件齐全后，才可点击“生成”。
2. 库存报告未上传不阻塞生成。
3. 单文件上传失败可独立重试。
4. 任一必需文件路径失效时，阻断并提示重新上传。
5. 成功后触发下载，页面保留本次参数与上传状态。
6. 点击 `上周` 按钮后，日期区间自动填充为“上周一 - 上周日”，用户仍可手动修改。

## 6. 校验规则

- 商业/付款报告：`.csv`
- 广告报告：`.xlsx`
- 库存报告：`.txt`
- 开始日期 <= 结束日期

## 7. API契约（现脚本）

1. `POST /upload-file`（产品分析蓝图）
- `multipart/form-data`
- 返回 `file_path`

2. `POST /submit`
- 提交参数与已上传文件路径
- 返回 xlsx 文件流

## 8. 验收标准（V1）

1. 可完成 3必需+1可选 文件上传与状态展示。
2. 可成功生成并下载分析文件。
3. 库存文件缺失时仍可生成主sheet。
4. 所有异常均可见、可重试。

## 9. 已确认规则

1. 页面名称与菜单名称统一为“产品分析”。
2. 日期范围规则已确认：仅要求 `report_start_date <= report_end_date`，不强制同周。
3. 页面展示主要指标口径说明（利润、ACOS、SP占比等）。
4. 不做“仅生成主sheet（不含库存详情）”显式开关。
5. 上传区支持“拖拽识别 + 批量投递”，识别规则见《数据分析-文件识别规范》。
