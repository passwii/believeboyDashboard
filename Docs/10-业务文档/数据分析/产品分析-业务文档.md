# 数据分析-产品分析 业务文档

## 1. 功能目标

融合业务报表、付款报表、广告报表、库存报表（可选）与基础SKU信息，生成 SKU 级财务与流量经营分析文件。

## 2. 输入范围

必需文件：

- 商业报告 `business_report`（csv）
- 付款报告 `payment_report`（csv）
- 广告产品报告 `ad_report`（xlsx）

可选文件：

- 库存报告 `inventory_report`（txt，制表符分隔）

上传 `file_type` 统一规则：

- `business_report`
- `payment_report`
- `ad_report`
- `inventory_report`

基础数据：

- `apps/model_file/BLF_Basic_Info.csv`（按 `project_name` 过滤）

参数：

- `project_name`
- `report_start_date`
- `report_end_date`

## 3. 处理流程

1. 校验参数与文件路径。
2. 读取三类必需报表 + 基础信息表。
3. 聚合广告数据（曝光、点击、花费、广告订单、广告销售额）。
4. 从付款报表计算实际销售/退款、平台佣金、FBA配送费。
5. 与业务报表（流量与销量）合并，形成SKU总览。
6. 计算经营指标（转化、CPC、ACOS、利润率等）。
7. 追加“汇总”行。
8. 写入模板 `product_analysis_template.xlsx`。
9. 若提供库存文件，追加“库存详情”sheet并联动“本周销量”。

## 4. 主要输出字段（产品分析sheet）

- 基础：`日期, SKU, ASIN`
- 业务：`总销量, 总销售额, 页面浏览量, 总访客, 总转化`
- 广告：`广告展示量, 广告点击量, 广告点击率, 广告订单量, 广告单占比, 广告转化率, 广告花费, 广告销售额, CPC, ACOS, SP占比`
- 自然：`自然流量, 自然流量占比, 自然单, 自然单转化`
- 财务：`产品FOB, 成本占比, 销售头程, 头程占比, FBA配送费, 配送费占比, 平台佣金, 佣金占比, 总成本, 总成本占比, 利润, 利润率, 实际销售额, 实际销售量, 实际退款额, 实际退款量, 平均售价, 退款率`

## 5. 关键计算口径（示意）

- `总转化 = 总销量 / 页面浏览量`
- `广告点击率 = 广告点击量 / 广告展示量`
- `广告单占比 = 广告订单量 / 总销量`
- `CPC = 广告花费 / 广告点击量`
- `ACOS = 广告花费 / 广告销售额`
- `利润 = 实际销售额 - 总成本 - 广告花费 - 实际退款额`
- `利润率 = 利润 / 实际销售额`

## 6. 项目特例

- 项目名包含“宝勒”时，会读取 `宝勒_FBM.csv` 并将 FBM 费用加到 `总销售额`。

## 7. 输出文件

- 文件名：`{project_name}_product_analysis_{report_date}.xlsx`
- 主sheet：`产品分析`
- 可选sheet：`库存详情`

## 8. 异常处理

- 缺少必需文件：提示重新上传
- 可选库存文件不存在：提示后继续生成主文件
- 基础信息未匹配到项目：打印错误日志（当前不中断）

## 9. 已确认规则

1. 页面与菜单命名统一为“产品分析”。
2. 上传 `file_type` 统一为：`business_report | payment_report | ad_report | inventory_report`。
3. 库存报告固定为 `txt`（制表符分隔）。
4. 日期范围规则：仅要求 `report_start_date <= report_end_date`，不强制同周。
