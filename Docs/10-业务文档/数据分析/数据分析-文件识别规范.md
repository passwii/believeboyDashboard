# 数据分析-文件识别规范

用于统一数据分析页面的“拖拽识别/批量投递”规则，适用于销售日报、财务月报、产品分析。

## 1. 识别原则

1. 优先按“文件内容特征”识别。
2. 内容无法识别时，按“文件名兜底规则”识别。
3. 识别结果用于自动填充上传卡片；不匹配当前页面所需类型的文件，提示并跳过。
4. 若同批次识别出多个同类型文件，默认取首个，其余提示“重复文件已跳过”。

## 2. 识别规则

### 2.1 订单文件（`sales_report`）

- 文件格式：`.txt`
- 内容特征：第一行包含 `amazon-order-id`
- 文件名兜底：文件名以 `or` 开头（兼容历史命名）

### 2.2 库存文件（`inventory_report`）

- 文件格式：`.txt`
- 内容特征：第一行包含 `snapshot-date`
- 文件名兜底：文件名包含 `fba`（兼容历史命名）

### 2.3 广告报表（`ad_report`）

- 文件格式：`.xlsx`
- 文件名特征：文件名包含 `ad`、`广告`、`推广` 任一关键词

### 2.4 付款报告（`payment_report`）

- 文件格式：`.csv`
- 内容特征：第一行包含 `Includes Amazon Marketplace`

### 2.5 月度总结PDF（`monthly_summary_pdf`）

- 文件格式：`.pdf`
- 文件名特征：同时包含 `monthly` 与 `summary`
- 标准命名示例：`2026JanMonthlyUnifiedSummary.pdf`

## 3. 前端交互要求

1. 支持拖拽多个文件到识别区，自动完成识别与分发。
2. 识别日志需在页面可见（成功映射、跳过原因、失败原因）。
3. 支持“识别后批量上传”与“单卡片手动上传”两种方式并存。
4. 单卡片手动选择文件时，仍保留原有格式校验和重传能力。
