# 数据分析-财务月报 业务文档

## 1. 功能目标

基于亚马逊 Payment Range Report（月度结算报表）与月度汇总 PDF 自动生成“月度财务报表”，输出多 sheet 核算文件，用于财务复盘与费用核对。

## 2. 业务范围

- 输入：Payment Range Report（`csv`）+ Monthly Unified Summary（`pdf`）
- 输出：`月度财务报表_{项目名}_美国站_{report_month}.xlsx`
- 处理粒度：按交易类型拆分、按收入/支出核算、按SKU统计销售退款明细

## 3. 输入规则

### 3.1 必填参数

- `project_name`
- `report_month`
- `payment_report_path`
- `summary_pdf_path`

### 3.2 项目名来源

- 来源：数据库 `projects`（前端调用 `/api/v1/projects`）
- 前端优先使用项目名下拉，减少手填错误

### 3.3 文件规则

- 允许格式：`csv` + `pdf`
- 上传类型：`payment_report` + `monthly_summary_pdf`
- 命名示例：
  - `2026JanMonthlyUnifiedTransaction.csv`
  - `2026JanMonthlyUnifiedSummary.pdf`
- 数据读取参数：`skiprows=7`、`thousands=","`

## 4. 核心处理流程

1. 校验参数与文件存在性。
2. 读取 Payment CSV 与 Summary PDF，并归档原始文件到项目 `tmp`。
3. 依据 `type / fulfillment / description` 做交易分类。
4. 计算收入项、支出项、平台推广占比、信用卡扣款等指标。
5. 生成多张结果表：总览草稿、报表核算、交易一览、SKU明细、各分类明细。
6. 写入 Excel 后统一套样式（首行冻结、边框、字体、列宽规则）。
7. 返回下载文件流。

## 5. 关键分类与计算口径

### 5.1 收入口径（示意）

- 非FBA销售与退款
- FBA销售与退款（含退款其他费用）
- 库存赔偿、清算收入
- 运费、礼包费、促销折扣、拒付退款等

### 5.2 支出口径（示意）

- 平台佣金（FBM/FBA）及相关退款
- FBA派送费及退款
- 仓储及入库服务费
- 服务费（不含广告）
- 广告费与广告退款
- 清算费用、调整项等

### 5.3 派生指标

- 平台推广费用占比：`abs(广告费) / 收入合计`
- 亚马逊回款金额：`PT4收入合计 + PT4支出合计`

## 6. 输出文件与Sheet

脚本当前输出包含（按写入逻辑）：

- `总览草稿`
- `报表核算`
- `交易一览`
- `销售SKU明细`
- `退款SKU明细`
- `所有订单` / `所有退款`
- `FBM 订单` / `FBM 退款`
- `FBA 订单` / `FBA 退款`
- `FBA库存赔偿` / `其他赔偿`
- `清算费用` / `拒付退款`
- `FBA仓储及入库服务费`
- `服务费（不含广告）`
- `广告费` / `广告退款`

## 7. 异常处理

- 参数缺失：提示“请填写所有必填项并上传文件”
- 文件不存在：提示重新上传
- 处理异常：返回失败并记录日志

## 8. 日志要求

- 上传月报文件（成功/失败/异常）
- 生成月报（成功/失败）

## 9. 待确认项

1. `report_month` 的输入格式固定为 `YYYY-MM`。
2. 服务费分类口径是否完全按当前脚本，还是需按财务口径调整。
3. `X-Form-Reset: true` 是否保留为前端表单重置信号。
4. 是否需要导出“仅总览版”（简化版）给非财务角色。
