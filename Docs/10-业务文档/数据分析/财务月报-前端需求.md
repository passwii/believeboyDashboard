# 数据分析-财务月报 前端需求

## 1. 页面目标

完成“选择项目 -> 上传交易CSV+月度PDF -> 生成月报 -> 下载Excel”的闭环。

## 2. 路由与导航

- 建议路由：`/dashboard/data-analysis/monthly-report`
- 菜单：`数据分析 > 财务月报`

## 3. 页面结构

1. 页面头部：标题“财务月报”与简述。
2. 参数区：项目名下拉、报表日期。
3. 上传区：交易 CSV + 月度 Summary PDF 两张上传卡片。
4. 操作区：生成月报按钮、loading状态。
5. 反馈区：成功/失败提示与下载结果。

## 4. 字段定义

- `project_name: string`（必填，下拉来源数据库 `projects`）
- `report_month: string`（必填，月份值，格式 `YYYY-MM`）
- `payment_report_path: string`（上传成功返回）
- `summary_pdf_path: string`（上传成功返回）

月份选择要求：

- 使用“月份选择”控件（非自然日）。
- 预置提供 2026 年上半年选项：
- `2026-01`
- `2026-02`
- `2026-03`
- `2026-04`
- `2026-05`
- `2026-06`

上传接口字段：

- `file`
- `project_name`
- `file_type = payment_report | monthly_summary_pdf`

## 5. 交互规则

1. 未选项目名时禁用上传。
2. 两个文件都上传成功后才允许“生成月报”。
3. 上传失败支持重试。
4. 生成成功后自动下载文件。
5. 若响应头含 `X-Form-Reset=true`，前端重置表单与上传状态。

## 6. 校验与提示

- 仅允许 `.csv` + `.pdf`
- 文件命名必须匹配：
  - `2026JanMonthlyUnifiedTransaction.csv`
  - `2026JanMonthlyUnifiedSummary.pdf`
- 项目名、日期、文件缺一不可
- 失败提示显示后端错误文本

## 7. API契约（现脚本）

1. `POST /api/v1/uploads`
- `multipart/form-data`
- `file_type = payment_report | monthly_summary_pdf`

2. `POST /api/v1/monthly-reports`
- 提交 `project_name/report_month/transaction_file_id/summary_pdf_file_id`
- 返回 `job_id`，由前端轮询任务状态后下载结果

3. `GET /api/v1/jobs/{job_id}` + `GET /api/v1/jobs/{job_id}/result`
- 用于状态轮询与最终文件下载

## 8. 验收标准（V1）

1. 能加载项目名下拉并选择。
2. 支持上传并显示 CSV+PDF 文件状态。
3. 能成功生成并下载月报。
4. 异常有明确提示，不出现卡死。

## 9. 已确认规则

1. 日期控件使用“月份选择”（不是自然日选择）。
2. 页面展示本次生成的 sheet 说明，固定展示 2 个 sheet：`报表核算`、`总览草稿`。
3. 月份选择预置提供 2026 年上半年（`2026-01` 至 `2026-06`）。
4. 上传区支持“拖拽识别 + 批量投递”，识别规则见《数据分析-文件识别规范》。
