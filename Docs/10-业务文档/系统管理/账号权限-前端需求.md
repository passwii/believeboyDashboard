# 账号权限-前端需求（NextAuth + shadcn）

## 1. 页面与路由

- 登录页：`/login`
- 仪表盘：`/dashboard`
- 系统管理-账号管理：`/dashboard/system-management/account-management`

## 2. 会话数据约定

`session.user` 至少包含：

- `name: string`
- `email: string`
- `isAdmin: boolean`

字段映射：

- `isAdmin` <-> 数据库 `is_admin`

## 3. 菜单显示规则

- `isAdmin = true`：显示 `NavAdmin`（系统管理菜单）。
- `isAdmin = false`：不渲染 `NavAdmin`。

## 4. 路由拦截规则

- 未登录访问 `/dashboard/*`：跳转 `/login`。
- 非管理员访问 `/dashboard/system-management/*`：跳转 `/dashboard` 并提示无权限。

## 5. 账号管理页功能

列表字段：

- 名称（`name`）
- 邮箱（`email`）
- 管理员（`is_admin`）
- 状态（`is_active`）
- 更新时间（`updated_at`）

操作：

- 新建用户
- 启用/停用
- 设置/取消管理员
- 重置密码

## 6. shadcn 组件建议

- 表格：`table`
- 筛选输入：`input`
- 新建/重置弹窗：`dialog`
- 布尔开关：`switch` 或 `checkbox`
- 操作按钮：`button` + `dropdown-menu`

## 7. 验收

- 普通用户永远看不到系统管理菜单。
- 管理员可进入账号管理并完成权限维护。
- 刷新页面后权限状态与后端保持一致。
