# 账号权限-业务文档（草案待确认）

## 1. 目标

- 支持两类账户：普通用户、管理员。
- 登录后按角色控制前端菜单与页面访问权限。
- 在 `系统管理 -> 账号管理` 提供人工维护账号权限能力。

## 2. 角色定义

### 普通用户（`is_admin = false`）

- 可访问业务页面（如运营总览、数据分析、数据管理）。
- 不显示 `系统管理` 菜单组。
- 不可直接访问任何 `系统管理/*` 页面（即使手动输入 URL）。

### 管理员（`is_admin = true`）

- 拥有普通用户全部能力。
- 显示并可访问 `系统管理` 菜单组。
- 可在 `系统管理 -> 账号管理` 中维护用户的管理员权限。

## 3. 用户数据规范

核心业务字段（你指定）：

- `name`：名称，必填。
- `email`：邮箱，必填，唯一（大小写不敏感）。
- `is_admin`：是否管理员，布尔值。

为支持登录能力，额外字段：

- `password_hash`：密码哈希（不存明文）。
- `is_active`：账号是否启用，默认启用。
- `created_at` / `updated_at`：审计时间。

## 5. 前端权限规则（NextAuth 集成阶段执行）

- 登录成功后从会话中读取 `is_admin`。
- 仅当 `is_admin = true` 时渲染 `NavAdmin`（系统管理菜单）。
- 路由守卫规则：
  - 未登录：跳转登录页。
  - 已登录但非管理员访问 `系统管理/*`：返回 403 或跳转到 `/dashboard`。

## 6. 账号管理页职责

页面位置：`系统管理 -> 账号管理`

最小操作集：

- 新增用户（名称、邮箱、初始密码、是否管理员）。
- 启用/停用用户（`is_active`）。
- 切换管理员权限（`is_admin`）。
- 重置用户密码（重算 `password_hash`）。

## 7. 验收标准

- 普通用户登录后看不到 `系统管理` 菜单。
- 管理员登录后可看到并访问 `系统管理`。
- 普通用户直接访问 `系统管理/*` 被拒绝。
- 管理员可在账号管理页修改用户 `is_admin` 并即时生效。
