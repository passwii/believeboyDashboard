- 后续所有报表与利润分析都以该表为成本基准

## 表 1：项目成本表 `product_costs`

### 建表目的

- 维护每个项目下 SKU/ASIN 的成本信息
- 支持后续按项目、SKU、ASIN 进行成本查询与利润计算
- 为每日/每周/月度报表提供统一成本口径

### 字段设计（v1）

| 字段名 | 类型 | 约束 | 说明 |
| --- | --- | --- | --- |
| `id` | `bigint` | PK, generated identity | 主键 |
| `project_name` | `text` | not null | 项目名（如：宝勒1店） |
| `sku` | `text` | not null | SKU |
| `asin` | `text` | not null | ASIN |
| `first_leg_unit_cost` | `numeric(12,2)` | not null default 0, check >= 0 | 头程单价 |
| `fob_unit_cost` | `numeric(12,2)` | not null default 0, check >= 0 | FOB 单价 |
| `currency` | `text` | not null default 'USD' | 币种（先固定 USD） |
| `source_file` | `text` | nullable | 来源文件名 |
| `created_at` | `timestamptz` | not null default now() | 创建时间 |
| `updated_at` | `timestamptz` | not null default now() | 更新时间 |

### 约束与索引

- 唯一约束：`unique(project_name, sku, asin)`
- 检查约束：
  - `first_leg_unit_cost >= 0`
  - `fob_unit_cost >= 0`
- 索引：
  - `idx_product_costs_project_name`
  - `idx_product_costs_sku`
  - `idx_product_costs_asin`

### 导入规则（CSV -> DB）

- CSV 字段映射：
  - `project_name` -> `project_name`
  - `SKU` -> `sku`
  - `ASIN` -> `asin`
  - `头程单价` -> `first_leg_unit_cost`
  - `FOB单价` -> `fob_unit_cost`
- 去空格：`project_name/sku/asin` 在入库前 `trim`
- 空值策略：
  - 成本为空时按 `0` 处理（与当前数据习惯一致）
- 写入策略：
  - 使用 upsert，冲突键：`(project_name, sku, asin)`
  - 冲突时更新成本与 `updated_at`

### Supabase SQL 草案（v1）

```sql
create table if not exists public.product_costs (
  id bigint generated always as identity primary key,
  project_name text not null,
  sku text not null,
  asin text not null,
  first_leg_unit_cost numeric(12,2) not null default 0 check (first_leg_unit_cost >= 0),
  fob_unit_cost numeric(12,2) not null default 0 check (fob_unit_cost >= 0),
  currency text not null default 'USD',
  source_file text,
  created_at timestamptz not null default now(),
  updated_at timestamptz not null default now(),
  constraint product_costs_project_sku_asin_key unique (project_name, sku, asin)
);

create index if not exists idx_product_costs_project_name on public.product_costs(project_name);
create index if not exists idx_product_costs_sku on public.product_costs(sku);
create index if not exists idx_product_costs_asin on public.product_costs(asin);
```
