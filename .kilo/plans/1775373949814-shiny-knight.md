## Feature 1: Code Display Optimization

### Goal
Add syntax highlighting with enhanced code block features.

### User Preferences
- Library: `react-syntax-highlighter`
- Features: Copy button, Language label, Line numbers

### Implementation

**1. Install syntax highlighting library**
```bash
cd frontend && pnpm add react-syntax-highlighter
```

**2. Update `AIChatMessageContent` component (`frontend/components/ai-chat-message-content.tsx`)**
- Import `SyntaxHighlighter` from `react-syntax-highlighter`
- Import a theme (e.g., `oneDark` or custom)
- Create custom code block rendering with:
  - **Copy button** (top-right): Click to copy, shows "Copied!" feedback
  - **Language label** (top-left): Badge showing language (e.g., "python", "javascript")
  - **Line numbers**: Numbered lines for easier reference
  - **Syntax highlighting**: Prism-based highlighting
- Override the `<code>` and `<pre>` elements in ReactMarkdown

**3. Code block styling:**
```
┌─ javascript ──────────────────────── [📋 Copy]
│ 1 │ const foo = 'bar';
│ 2 │ console.log(foo);
└──────────────────────────────────────
```

## Feature 2: HTML Page Preview (Expandable/Collapsible)

### Goal
Allow users to preview HTML code snippets inline with expand/collapse toggle.

### Implementation

**1. Update `AIChatMessageContent` for HTML detection**
- Detect code blocks with language `html` or `htm`
- Show additional "Preview" toggle button

**2. Create expandable HTML preview section**
- "Preview" toggle button (collapsed by default)
- When expanded: sandboxed iframe (height ~400px, resizable)
- Security: `sandbox="allow-scripts"` attribute

**3. Layout for HTML code blocks:**
```
┌─ html ─────────────────────────────── [📋 Copy] [👁 Preview]
│ <div>Hello World</div>
└──────────────────────────────────────
│ ▼ Preview ─────────────────────────── [⤡ Expand]
│ ┌──────────────────────────────────┐
│ │     [iframe: HTML rendered]      │
│ └──────────────────────────────────┘
```
