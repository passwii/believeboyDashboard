# 侧边栏主题模式切换设计

## 背景

Dashboard 目前通过侧边栏底部的太阳 / 月亮按钮在浅色与深色之间二态切换。项目已使用 `next-themes`，并启用系统主题作为默认模式，但侧边栏没有入口选择“自动（跟随系统）”。同时，根主题 Provider 设置了 `disableTransitionOnChange`，因此切换时不会呈现连续的页面色彩过渡。

## 目标

- 在桌面侧栏提供浅色、深色、自动三种可持久化模式。
- 鼠标悬停主题按钮时打开选择菜单；点击、键盘也能操作。
- 在移动端导航抽屉内提供同样的主题菜单，以点击交互为主。
- 主题应用后以克制的图标动画和约 220ms 的页面颜色过渡提供反馈。
- 尊重系统减少动态效果设置，不影响既有导航和主题持久化。

## 非目标

- 不重做 Dashboard 配色、主题 token 或其他页面布局。
- 不新增设置后端、数据库字段或独立 localStorage key；继续使用 `next-themes` 的主题偏好持久化。
- 不加入整页缩放、圆形扩散遮罩、布局移动或逐卡片入场动画。
- 不把鼠标悬停在菜单选项上解释为立即更改主题；必须点击或键盘确认。

## 交互设计

### 桌面侧栏

- 保留窄侧栏底部主题按钮。
- 鼠标进入按钮时展开靠右的小菜单，离开按钮开始短暂关闭延迟；指针进入菜单时取消关闭，避免跨越按钮与菜单间距时菜单闪退。
- 点击按钮仍可打开 / 关闭菜单；键盘可通过现有 Radix DropdownMenu 行为打开、移动焦点、选择和 Escape 关闭。
- 菜单选项为“浅色”“深色”“自动（跟随系统）”，当前用户设置通过 radio 选中态显示。
- 悬停展开不抢键盘焦点；触发器和菜单均提供可访问名称与状态。

### 移动端

- 在移动导航抽屉底部增加“外观”入口。
- 点击入口打开同一组选项的小菜单；窄屏内菜单向上展开，避免依赖 hover。
- 选择模式后立即应用并关闭菜单；抽屉仍由用户自行关闭。

### 图标状态

- 浅色模式显示太阳图标，深色模式显示月亮图标，自动模式固定显示显示器图标。
- 仅用户选择不同模式时播放一次约 180ms 的轻微旋转 / 淡入动画；首次挂载、hydration 和系统自动适配不播放选择动画。

## 主题与状态实现

- 复用 `next-themes` 的 `theme`、`resolvedTheme` 与 `setTheme`，模式值为 `light`、`dark`、`system`。
- 提取一个共享主题菜单组件，桌面侧栏和移动抽屉通过不同的触发器外观与菜单方向复用同一组选项、状态和动画逻辑。
- 移除 Provider 上阻止所有 CSS 过渡的 `disableTransitionOnChange`；主题变化只通过共享主题选择器启动短暂的根元素过渡状态，不额外写入主题偏好。
- 主题色过渡仅覆盖颜色类 CSS 属性（文字色、背景色、边框色、SVG 色等），不改变尺寸、位置或滚动状态；使用未分层规则覆盖 Tailwind transition utilities，并在过渡结束后及时清除状态。
- 同一时间重复切换时重置清理计时器，避免旧计时器提前终止新过渡；组件卸载时清理计时器。
- `prefers-reduced-motion: reduce` 下禁用图标 keyframe，并将页面色彩过渡缩短至即时 / 极短时长。

## 错误与边界情况

- 客户端主题尚未挂载时渲染同尺寸的占位触发器，避免服务端与客户端主题图标不一致。
- 当前主题值缺失或无效时按 `system` 展示，不破坏现有 `next-themes` 默认值。
- 菜单无论通过悬停、点击、键盘或触屏打开，都能通过选项选择、Escape 或离开悬停区域关闭。
- `system` 模式固定显示显示器图标；系统偏好变化由 `next-themes` 自行更新实际解析主题。

## 文件边界

- 新增 `frontend/components/terminal/theme-mode-picker.tsx`：共享桌面 / 移动主题菜单、触发器、悬停延迟与用户选择动画触发。
- 新增 `frontend/components/terminal/theme-mode-picker.test.tsx`：验证悬停展开、模式选择、当前模式和过渡状态。
- 修改 `frontend/components/terminal/terminal-rail.tsx`：以共享选择器替换现有二态按钮。
- 修改 `frontend/components/terminal/terminal-shell.tsx`：在移动导航抽屉底部挂载共享选择器。
- 修改 `frontend/components/ui/dropdown-menu.tsx`：透传 Radix `onOpenAutoFocus`，供桌面 hover 展开时保持键盘焦点不被抢走。
- 修改 `frontend/app/layout.tsx`：允许共享主题颜色过渡。
- 修改 `frontend/app/globals.css`：定义短暂主题色过渡、图标动画和减少动态效果覆盖。
- 修改现有侧栏测试（如有必要）：更新旧二态按钮相关断言，保留轨道几何与图标尺寸契约。

## 验收标准

1. 桌面鼠标悬停侧栏主题按钮时菜单打开；移动指针进入菜单不会关闭，离开菜单后延迟关闭。
2. 点击与键盘操作均可打开菜单；选中浅色、深色或自动后调用对应 `setTheme` 值。
3. 触屏可从移动导航抽屉底部打开菜单并切换三种模式。
4. 当前设置有明确选中态；自动模式图标为显示器，浅 / 深模式分别为太阳 / 月亮。
5. 主题变化时页面颜色柔和过渡、图标仅在用户选择后短暂动效；不改变布局。
6. 系统减少动态效果时动画被关闭或缩短。
7. 相关组件测试、前端 lint 通过；变更仅属局部前端功能，按仓库规则运行目标测试和 lint。
