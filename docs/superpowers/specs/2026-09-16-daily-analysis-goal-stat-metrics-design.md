# 日报分析目标磁贴三指标口径设计

## 背景

`dashboard/operations/daily-analysis` 的 Stats 目标磁贴目前只显示一个“实际月度完成率”。用户需要同时看到三个独立指标，并在右侧用小一号字体显示简短标注。

现有“截止今日完成率”和“预估月度完成率”存在公式重复：

- 截止今日完成率 = 累计已完成 / 截至今日应完成
- 预估月度完成率 = 实际月度完成率 * 月度总天数 / 已过天数

两者化简后相同，不能作为两个独立指标展示。

## 决策

目标磁贴展示以下三个指标：

1. `进度`：沿用 `completion_vs_daily`，表示累计完成相对截至今日应完成的进度。
2. `月度`：沿用 `completion_vs_monthly`，表示累计完成相对整月目标的进度。
3. `速度`：当前日均销售额与剩余所需日均销售额之比，用于判断按当前节奏能否追平目标。

项目目标管理页的完整三环也采用同一口径，避免两个页面出现不同的第三个指标定义。

## 计算口径

速度指标使用：

```text
current_daily = achieved_amount / today_day
required_daily = (target_amount - achieved_amount) / (days_in_month - today_day)
pace_ratio = current_daily / required_daily
```

边界规则：

- `target_amount <= 0`、`today_day <= 0`、`days_in_month <= 0` 或任一输入非有限数时返回 `null`。
- 已完成目标时返回 `1`，展示为 `已达标`。
- 剩余天数为 `0` 且尚未达标时返回 `0`。
- 计算结果可为 `0` 以上任意值；圆环按 `0..1` 封顶，文字保留真实百分比。

## UI 设计

`GoalProgressStat` 保持现有磁贴尺寸和跳转行为：

- 左侧保留三环。
- 右侧标题仍为“目标进度”。
- 标题下展示三行紧凑指标，例如：

```text
进度  82.4%
月度  46.7%
速度  105.0%
```

- 每行左侧使用 `10px` 灰色简称，右侧使用 `11px` 百分比，并带与对应圆环一致的小色点。
- 小屏保持三行结构，不改为横向拥挤布局。
- 加载中、未设置目标和请求失败状态继续可用。
- 点击整个磁贴仍跳转到当前项目、站点的目标管理页。

## 测试

- 单元测试覆盖速度指标公式及边界条件。
- 组件测试确认 Stats 同时渲染 `进度`、`月度`、`速度` 和三个百分比。
- 项目目标管理页测试确认第三个指标改为“达成速度”。

## 不做

- 不新增“今日销售额”后端字段。
- 不增加新的页面或接口。
- 不修改目标管理页的圆环视觉布局。
