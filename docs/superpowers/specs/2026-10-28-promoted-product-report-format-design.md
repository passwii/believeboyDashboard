# 已推广商品广告报表新版格式适配设计

## 状态

设计已由用户确认，按本设计实现新旧格式兼容。

## 背景

Amazon 已推广商品报告新版调整了表头：旧版分别提供“开始日期”“结束日期”，新版合并为“日期范围”；广告 SKU、ASIN、国家、货币、成本与归因指标也使用新列名。现有广告自动上传识别和入库只理解旧列，因此新版文件无法通过识别，日期和指标也无法写入现有详情表。

## 目标

- 使自动上传链路识别新版已推广商品报告，并继续识别旧版。
- 从新版“日期范围”读取起止日期；从“投放广告活动的国家/地区”识别站点。
- 将新版列映射到既有推广商品详情行字段，不改数据库结构。
- 保留原始导出列名和 raw row 内容。

## 实现设计

- 在 REPORT_SPECS 中为新版已推广商品报告增加单独签名，报告类型仍使用 ad_promoted_product_report。新版 SKU/ASIN 列参与项目自动匹配。
- 扩展共享日期范围解析，支持 2026年10月26日 - 2026年10月26日 以及旧版起止日期；广告专用识别和通用广告校验都复用该解析。
- 识别和详情入库均兼容新国家列，并通过现有 normalize_country 规范化国家代码后写入两位国家字段。
- 入库按字段别名读取，旧版与新版共享现有模型：广告 SKU/ASIN、展示量、点击量、CPC、花费/总成本、订单、销量、销售额、ROAS、转化率、推广与光环单位/销售额、广告组合与货币。
- 新版点击率和点击购买率以百分数写入模型比例值；旧版已有比例列保持现有换算方式。新版没有直接 ACOS 列时，若销售额和成本有效则用成本除销售额推导，否则保留零值。
- 新版多日汇总日期范围仍遵守自动上传当前的单日报表入库约束；识别响应保留日期范围，并给出已有非单日报表提示。

## 新版字段映射

| 既有详情字段 | 新版报告列 |
|---|---|
| campaign_name / ad_group_name | 广告活动名称 / 广告组名称 |
| ad_sku / ad_asin | 推广的商品 SKU-Advertised product SKU / 推广的商品编号 |
| impressions / clicks | 展示量 / 点击量 |
| ctr / cpc / spend | 点击率（百分数） / CPC / 总成本 |
| orders_7d / units_7d / sales_7d | 购买量 / 由点击产生的已售商品数量 / 销售额 |
| roas / cvr_7d | 归因于点击的 ROAS / 点击购买率（百分数） |
| ad_sku_units_7d / other_sku_units_7d | 已售商品数量（推广） / 已售商品数量（光环） |
| ad_sku_sales_7d / other_sku_sales_7d | 推广商品的销量 / 销售额（光环） |
| country / currency / portfolio_name | 投放广告活动的国家/地区 / 预算货币 / 广告组合名称 |

## 非目标

- 不适配其他广告报表的新版本；拿到各自样例后再单独扩展。
- 不修改前端自动上传页面、模型或数据库迁移。
- 不改变现有多日汇总拒绝入库规则。

## 验收标准

- 新旧格式均识别为 ad_promoted_product_report，新列 SKU/ASIN 能参与项目匹配。
- 新版日期范围和国家被识别；单日日期与 US 站正确返回。
- 新版关键指标映射到已有字段，百分数正确转换为小数比例；旧版入库映射保持原行为。
- 目标后端测试通过，改动不涉及用户已有的 CRM 工作区文件。
